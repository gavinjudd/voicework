# Voicework engineering and writing boundaries

Read README.md and docs/BUILD_CONTRACT.md before editing. Keep the app runnable with Python 3.9+ stdlib and a browser unless there is an explicit reason to introduce dependencies. Inspect existing patterns; preserve user data and unrelated work.

This product learns wording AND presentation for particular contexts. Never silently convert a selected AI answer, source ownership, or a style similarity score into proof of user authorship. Only explicitly confirmed, non-held-out samples are positive authored evidence. Feedback is a separate record. Context inference is provisional and editable.

Keep all private writing/database files out of Git. Do not seed real user memory or personal archives. Test with fictional/synthetic text. Treat imported content and model output as untrusted data. Reject malformed inputs before persistence and never render samples as HTML. Local discovery is opt-in, bounded, read-only, and must report skips/errors.

Codex is an explicit generation provider. Do not claim hidden desktop memory access, a fine-tuned model, measured fidelity, working Drive API access, complete computer coverage, or secure deletion without evidence. Offline mode is rehearsal; no silent provider fallback. XP measures contributions only. Controls change style but must not authorize factual invention.

Run relevant unit/integration tests and browser-check changed flows. An export is user-controlled and should exclude raw examples by default. Holdout text must never leak into prompts, descriptive training patterns or example exports.
